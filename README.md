## 🧭 工作方式

> 🧭 **场景优先**：先明确真实问题和使用者，再决定功能。

> 🚀 **尽早可运行**：用最小可用版本验证方向，快速迭代。

> 📊 **反馈驱动**：结合界面、数据和真实反馈修正产品。

> 🤖 **自动化优先**：重复、可流程化的工作交给脚本或 AI。
