# Yohoia GitHub Profile README

This repository is the special GitHub profile repository `Yohoia/Yohoia`. Its `README.md` is displayed at the top of <https://github.com/Yohoia>.

## Files

```text
README.md                            Personal profile content
assets/readme/header.png             Custom raster profile hero image
.github/workflows/update-readme.yml  Recent GitHub activity workflow
```

## Dynamic modules

| Module | Source |
| --- | --- |
| Profile views | `komarev.com/ghpvc` |
| Followers / repositories / repo signals | Shields.io |
| Stats, top languages, streak, trophies, activity graph | GitHub README stats services |
| Recent GitHub activity | GitHub Actions, every 6 hours |

The activity workflow can also be run manually:

```text
Actions → Update GitHub activity → Run workflow
```

## Maintenance

- Update project descriptions in `README.md` whenever a product positioning changes.
- Social links are listed in the first screen and the contact table.
- Replace `assets/readme/header.png` when you want to update the hero image.
- Keep the color palette consistent with the hero when changing dynamic-card query parameters.
